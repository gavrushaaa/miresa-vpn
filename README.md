# miresa VPN — статическая версия

Фронтенд на React, Vite и Tailwind CSS. Go API и SQLite не запускаются в этой версии и исключены из статической публикации.

## Локальный просмотр

```sh
npm install
npm run dev
```

## Сборка

```sh
npm run build
```

Публикация GitHub Pages запускается автоматически при отправке изменений в ветку `main`. В статической версии карточки тарифов отображаются из данных фронтенда; вход и регистрация отключены, данные личного кабинета не сохраняются.
